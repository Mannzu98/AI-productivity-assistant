# AI Workplace Productivity Assistant

## Project Overview

AI Workplace Productivity Assistant is a modern AI-powered web application designed to help professionals automate common workplace tasks. The platform improves productivity by using Artificial Intelligence to generate professional emails, summarize meeting notes, organize tasks, conduct research, and provide an interactive AI assistant.

The application features a modern dashboard with a responsive design, allowing users to work efficiently on desktop and mobile devices. It also promotes responsible AI usage by encouraging users to review AI-generated content before making business decisions.

---

## Features

### 📧 Smart Email Generator

* Generate professional emails instantly.
* Support multiple tones:

  * Formal
  * Friendly
  * Persuasive
* Editable AI-generated responses.

### 📝 Meeting Notes Summarizer

* Summarize long meeting notes.
* Extract:

  * Key points
  * Action items
  * Decisions
  * Deadlines

### 📅 AI Task Planner

* Create daily or weekly schedules.
* Prioritize tasks based on urgency and importance.
* Improve time management.

### 🔍 AI Research Assistant

* Summarize topics and articles.
* Provide insights and recommendations.
* Simplify complex information.

### 💬 AI Chat Assistant

* Interactive workplace chatbot.
* Respond to user questions.
* Assist with productivity tasks.

### 🛡 Responsible AI

* AI disclaimer included.
* Encourages human review of AI-generated outputs.
* Promotes ethical AI usage.

### 📱 Responsive Dashboard

* Modern sidebar navigation.
* Mobile and desktop friendly.
* Clean SaaS-inspired interface.

## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/ai-workplace-productivity-assistant.git
```

### 2. Navigate to the project folder

```bash
cd ai-workplace-productivity-assistant
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Visit:

```bash
http://localhost:5173
```
